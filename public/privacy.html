c-rat-o — Privacy Policy & Terms of Service

Effective date: 26 August 2026

Privacy Policy Terms of Service

c-rat-o (“the App”) is a client-side application for recording and reporting insect pest monitoring data within an archive. It is developed and maintained by Ben Foley (“the developer”). This document describes how the App handles data and the terms under which it is provided.

Privacy Policy

1. Data storage

The App has no server component. All data entered into the App — trap and room configuration, species and season lists, trap-check records, and trap photographs — is stored locally in the web browser’s storage on the device in use. The developer does not receive, collect, or have access to this data.

2. Google Drive integration

The App offers an optional feature to back up and synchronize the data described above via the user’s own Google Drive account, using Google’s drive.file scope. Under this scope the App can access only the files it has itself created in the user’s Drive; it cannot view, modify, or delete any other file. Authentication is handled entirely in the browser: access tokens are held in memory for the current session only and are never sent to, or stored on, any server operated by the developer. The only data written to Drive is a single backup file containing the data described in Section 1.

3. No tracking or third-party sharing

The App does not use cookies, analytics, advertising, or tracking technologies, and does not transmit data to any third party. The sole exception is the user’s own Google Drive, accessed only if and when the user explicitly enables the sync feature described in Section 2.

4. Data retention and deletion

Locally stored data persists until the user clears their browser’s site data or removes it using the App’s own data-reset function. Data stored in the user’s Google Drive persists until the user deletes it or revokes the App’s access via their Google Account permissions.

5. Changes to this policy

This policy may be revised from time to time. The effective date above reflects the date of the most recent revision.
